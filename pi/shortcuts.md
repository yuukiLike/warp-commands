# Pi 快捷键速查

Pi 1.5.0 · macOS / 普通 Linux 默认键位。当前设置看 `/hotkeys`，选择器内看底部提示。

## 主输入框

| 按键 | 操作 |
| --- | --- |
| `Ctrl+L` | 选择模型 |
| `Ctrl+P` / `Ctrl+Shift+P` | 下一个 / 上一个模型 |
| `Shift+Tab` | 切换思考级别 |
| `Escape` | 中止当前运行 |
| `Shift+Enter` | 换行（需终端支持） |
| `Alt+Enter` | 追加请求，等当前工作结束后执行 |
| `Ctrl+V` | 粘贴文本或图片 |
| `Ctrl+O` | 折叠 / 展开工具输出 |
| `Ctrl+T` | 折叠 / 展开思考内容 |
| `Ctrl+C` | 清空输入 |
| `Ctrl+D` | 输入为空时退出 |

## 选择器

| 界面 | 按键 | 操作 |
| --- | --- | --- |
| `/model` | 输入关键词 | 搜索模型或供应商 |
| `/model` | `Enter` | 切换模型 |
| `/model` | `Ctrl+S` | 切换并保存为默认模型 |
| `/model` | `Tab` | 常用 / 全部（已设置常用范围时） |
| `/thinking` | `Enter` / `Ctrl+S` | 应用级别 / 应用并保存 |
| `/scoped-models` | `Ctrl+X` | 取消全选；有搜索词时只取消搜索结果 |
| `/scoped-models` | `Enter` | 勾选 / 取消当前模型 |
| `/scoped-models` | `Ctrl+S` | 保存常用范围 |
| 以上界面 | `Escape` | 返回 |

精简模型列表：[从零勾选常用模型](README.md#用界面从零勾选)。
